🆘 TROUBLESHOOTING:

"Python not found"
  → Install from python.org

"AWS profile 'hackathon' not found"
  → Run: aws configure --profile hackathon

"Bedrock access denied"
  → AWS Console → Bedrock (us-east-1)
  → Model access → Enable Claude 3.5 Sonnet

"Frontend build failed"
  → Check Node.js version: node --version (need 18+)
  → Delete node_modules, run: npm install

"Deployment failed"
  → Check CloudFormation console for errors
  → Ensure IAM permissions (AdministratorAccess)
